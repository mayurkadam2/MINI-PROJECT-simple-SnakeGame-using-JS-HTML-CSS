# 🐍 Snake Game

A classic **Snake Game** built from scratch using pure HTML, CSS, and JavaScript — no libraries, no frameworks, just vanilla web development.

> Guide the snake, eat the food, grow longer — and don't hit the walls or yourself! 🎮

---

##  Live Demo

👉 **[Play Now](https://mayurkadam2.github.io/MINI-PROJECT-simple-SnakeGame-using-JS-HTML-CSS/)** *(enable GitHub Pages if not already active)*

---

## Features

- **Classic Snake Gameplay** — Eat food to grow longer and rack up your score
- **Keyboard Controls** — Arrow keys to move the snake in all 4 directions
- **Collision Detection** — Game ends when the snake hits a wall or itself
- **Score Tracking** — Live score counter that increases as you eat food
- **Restart Option** — Replay instantly after game over without refreshing
- **Speed Increase** — Snake speeds up as your score grows, making it harder
- **Clean UI** — Minimal, distraction-free game board

---

## 🛠️ Tech Stack

| Technology | Role |
|---|---|
| HTML5 Canvas | Drawing the game board, snake, and food |
| CSS3 | Styling the page layout and UI |
| JavaScript (Vanilla) | Game loop, movement logic, collision detection |

> Zero dependencies. Just a browser and you're good to go.

## 🎮 How to Play

| Key | Action |
|---|---|
| ⬆️ Arrow Up | Move Up |
| ⬇️ Arrow Down | Move Down |
| ⬅️ Arrow Left | Move Left |
| ➡️ Arrow Right | Move Right |

- 🍎 **Eat the food** → Snake grows + score increases
- 💀 **Hit a wall or yourself** → Game Over
- 🔁 **Click Restart** → Play again

## 🧠 Concepts Used

Building this project helped me practice and understand:

- **HTML5 Canvas API** — Drawing shapes and updating them in real time
- **Game Loop** — Using `setInterval` to continuously redraw the game state
- **Keyboard Events** — Listening to `keydown` events for player input
- **Collision Detection** — Checking if the snake's head overlaps with walls or its own body
- **Array Manipulation** — Managing the snake's body as an array of positions
- **DOM Manipulation** — Updating the score display dynamically
